# Segurança — EFCsys

## Quando usar
Autenticação, autorização, dados sensíveis, APIs ou operações privilegiadas.

## Instruções
- Aplicar menor privilégio.
- Não confiar em validação apenas no frontend.
- Não expor segredos.
- Validar acesso no servidor/banco.
- Revisar impacto de RLS e permissões.
- Nunca reduzir segurança apenas para contornar um bug.
- Consulte `../../shared/security-rules.md`.
