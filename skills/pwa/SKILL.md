# PWA — EFCsys

## Quando usar
Instalação, manifest, ícones, splash, cache e experiência standalone.

## Instruções
- Validar manifest e ícones necessários.
- Garantir comportamento responsivo/standalone.
- Não aplicar cache agressivo a dados dinâmicos sem invalidação.
- Prever atualização segura do service worker.
- Preservar funcionamento web quando instalação PWA não estiver disponível.
