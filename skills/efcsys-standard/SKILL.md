# EFCsys Standard

## Quando usar
Base para qualquer projeto EFCsys.

## Instruções
1. Preserve requisitos e arquitetura aprovados.
2. Faça a menor alteração segura que resolva a solicitação.
3. Não duplique funcionalidades, componentes ou regras.
4. Reutilize padrões existentes.
5. Separe regras globais das específicas do projeto.
6. Consulte os arquivos em `../../shared/` somente quando relevantes.
7. Não execute trabalho adicional não solicitado.
