# Coding Standards EFCsys

- Priorizar código simples, legível e sustentável.
- Preservar arquitetura existente quando funcional.
- Evitar duplicação e reutilizar componentes/utilitários.
- Alterar somente o necessário.
- Não adicionar dependências sem necessidade técnica.
- Manter tratamento de erros e estados de interface.
- Preservar responsividade e acessibilidade.
- Não quebrar funcionalidades existentes para implementar uma nova.
